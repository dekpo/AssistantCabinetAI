# Inventory sandbox (fictional only)

Fixtures for sprint 2a.5: the Work Folder inventory, file reference resolution, and the
anti-hallucination tests. Design: `docs/WORK-FOLDER-INVENTORY.md`. Acceptance:
`apps/desktop/src-tauri/tests/work_folder_inventory.rs`.

Everything here is invented. No name, date, finding or file name refers to a real person or a real
practice. Do not copy a file from a practice system into this tree — it is committed to Git, so
anything placed here is permanent and copied to every clone.

Generated by `python scripts/gen-sandbox-fixtures.py` from the repository root. Do not hand-edit
the binaries; change the generator and run it again.

## `flat/` — the counting fixture

Exactly **15 files**, no subdirectory: 6 TXT, 5 PDF, 1 DOCX, 2 PNG, 1 JPG. Ten can be read; five
cannot, and their unreadability is real rather than declared — the two scan PDFs carry no text
layer at all, and the three images hold nothing an engine can recognise.

| File | What it exercises |
| --- | --- |
| `assurance.txt`, `convocation.txt`, `horaires.txt` | Ordinary readable text files |
| `misleading.txt` | Claims the folder holds only 2 files, and that it is itself a `.pdf`. The inventory must contradict both |
| `report.txt` | Says "This is a PDF report." The extension stays `.txt` |
| `procedure.txt` | Refers to `fake-document.pdf`, which does not exist. Its text really is indexed, so a listing built from retrieved passages would pick the name up |
| `biologie.pdf`, `neurologie.pdf`, `courrier-cardiologie.pdf` | Native-text PDFs, indexed with no OCR engine present |
| `radiographie-scan.pdf`, `echographie-scan.pdf` | No text layer. Reported unreadable, never guessed at |
| `courrier-endocrinologie.docx` | A native-text Word letter |
| `patient-report.png` | Named as though it held a report; nothing is recoverable from it. The name must never become content |
| `illisible.png`, `ordonnance-illisible.jpg` | Unreadable images, PNG and JPEG |

## `nested/` — the path-resolution fixture

```text
2026/
  janvier/
    neurologie.pdf
  mars/
    biologie.pdf
    neurologie.pdf
administratif/
  assurance.txt
```

`neurologie.pdf` exists twice on purpose: a reference to the bare file name is genuinely
ambiguous, and the resolver must report that rather than pick the one that sorted first.
`biologie.pdf` is unique, so it resolves exactly — by path, by name, and by name without the
extension.
