# GP sandbox (fictional only)

All names, dates, findings, and file names here are invented. They are stand-ins for PDFs so the four admin prompts can be tried without a real inbox.

Do not copy files from a practice system into this tree. A `real/` folder is gitignored and must stay empty.

## How to try the prompts

| Prompt key | Input in this folder |
| --- | --- |
| `gp-referral-letter` | `notes/referral-notes-camille-exemple.txt` |
| `gp-certificate-draft` | `forms/certificate-form-hugo-bacasable.txt` |
| `gp-inbox-classify` | the five files in `inbox/` (treat them as unlabeled PDFs) |
| `gp-letter-summary` | `inbox/2026-03-10_specialist-letter.txt` |

Success for this prototype: a referral draft, a certificate draft from the form fields only, and a rename plan for the five inbox files. Nothing is sent. A human must review every output.
